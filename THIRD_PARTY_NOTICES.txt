2. COMPONENTS NOT BUNDLED IN THE RR-V INSTALLER
------------------------------------------------

Starting with RR-V 1.2.0, the following external executables are intentionally
not included in the RR-V onedir package or Installer. When the user chooses to
install required components, RR-V downloads them from their official distribution
sources into the user's LocalAppData RR-V tools directory.

yt-dlp Nightly Windows executable
  Project: https://github.com/yt-dlp/yt-dlp
  RR-V download channel: https://github.com/yt-dlp/yt-dlp-nightly-builds/releases
  Licensing note: yt-dlp source is released under the Unlicense, while the
                  official PyInstaller-bundled executable contains third-party

                  GPLv3+ terms according to the yt-dlp project.

FFmpeg / FFprobe - Gyan Release Essentials
  Project: https://ffmpeg.org/
  RR-V download channel: https://www.gyan.dev/ffmpeg/builds/#release-builds
  License of the Gyan static builds used by RR-V: GPLv3

                      each build on its builds page.

Deno

PyInstaller's licensing exception permits generated application bundles to be

licenses of bundled dependencies. PyInstaller itself is not presented as part

Project: https://pyinstaller.org/


4. SOURCE AVAILABILITY AND LICENSE COPIES
-----------------------------------------

The RR-V release directory contains a licenses folder generated by
BUILD_RELEASE.ps1. It is intended to contain:

  - the Python license used by the release interpreter;
  - PySide6 / Qt / shiboken package license and metadata files available from the
    exact installed packages used for the build;
  - license and metadata files from the exact locked WPC runtime wheels;
  - RR-V Auth Helper source code;
  - SOURCE_OFFER.txt.

The bundled nodriver and yt-dlp-getpot-wpc Python sources are also present inside
RR-V's WPC runtime itself.

For source-code requests concerning LGPL/AGPL-covered components distributed by
RR-V, see SOURCE_OFFER.txt or contact:
