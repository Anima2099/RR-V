RR-V 1.1.2 final release checklist

Release rule
[ ] Keep the development source folder separate from build/dist output.
[ ] Keep a zipped source snapshot before every public build.
[ ] Remove temporary patch README/BAT files from the release source folder.

Before build
[ ] app\constants.py shows APP_VERSION = "1.1.2"
[ ] RR-V.version_info.txt shows FileVersion/ProductVersion 1.1.2
[ ] resources\icons\RR-V.ico and RR-V.png are the intended release icons
[ ] resources\tools\yt-dlp.exe is the intended Nightly build
[ ] resources\tools\ffmpeg.exe exists
[ ] resources\tools\ffprobe.exe exists
[ ] resources\tools\deno.exe exists (Deno 2.3.0+; current tested version recommended)
[ ] resources\wpc-provider\runtime contains WPC and nodriver
[ ] resources\wpc-provider\WPC_RUNTIME_LOCK.txt is present and keeps the regression-tested dependency set
[ ] The intended Python virtual environment is active in VS Code
[ ] Do not change WPC runtime lock versions for the 1.1.2 release without restarting YouTube regression tests
[ ] PyInstaller 6.15.0 or newer is installed when building with Python 3.14

Prepare YouTube support runtime
  powershell -ExecutionPolicy Bypass -File .\PREP_WPC_PROVIDER.ps1

The script rebuilds resources\wpc-provider\runtime from the exact regression-tested lock:
  yt-dlp-getpot-wpc 1.1.2 / nodriver 0.50.3 / mss 10.2.0 / websockets 16.1.1
  deprecated 1.3.1 / wrapt 2.3.0
It downloads each wheel with --no-deps, verifies the exact dist-info set, and removes
stale __pycache__ / .pyc files before packaging.

Build
  python -m PyInstaller --clean --noconfirm RR-V.spec

Expected output
  dist\RR-V.exe
