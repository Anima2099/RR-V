RR-V 1.2.0 community beta release checklist

Release rule
[ ] Keep the development source folder separate from build/dist output.
[ ] Keep the tested Git commit/branch as the release source reference.
[ ] Remove temporary patch/test files from the release source folder.

Before build
[ ] app\constants.py shows APP_VERSION = "1.2.0"
[ ] RR-V.version_info.txt shows FileVersion/ProductVersion 1.2.0
[ ] resources\icons\RR-V.ico and RR-V.png are the intended release icons
[ ] auth_helper\main.py and RR-V-Auth-Helper.spec are present
[ ] resources\wpc-provider\runtime contains WPC and nodriver
[ ] resources\wpc-provider\WPC_RUNTIME_LOCK.txt is present and keeps the regression-tested dependency set
[ ] The intended Python virtual environment is active in VS Code
[ ] PyInstaller is installed in the release virtual environment

External runtime tool policy (1.2.0+)
[ ] yt-dlp.exe is NOT required in resources\tools for packaging
[ ] ffmpeg.exe is NOT required in resources\tools for packaging
[ ] ffprobe.exe is NOT required in resources\tools for packaging
[ ] deno.exe is NOT required in resources\tools for packaging
[ ] RR-V installs missing yt-dlp / FFmpeg / FFprobe / Deno from their official distribution sources after launch
[ ] The built dist\RR-V tree contains none of those four external runtime executables

Prepare YouTube support runtime
  powershell -ExecutionPolicy Bypass -File .\PREP_WPC_PROVIDER.ps1

The script rebuilds resources\wpc-provider\runtime from the exact regression-tested lock:
  yt-dlp-getpot-wpc 1.1.2 / nodriver 0.50.3 / mss 10.2.0 / websockets 16.1.1
  deprecated 1.3.1 / wrapt 2.3.0
It downloads each wheel with --no-deps, verifies the exact dist-info set, and removes
stale __pycache__ / .pyc files before packaging.

Build
  powershell -ExecutionPolicy Bypass -File .\BUILD_RELEASE.ps1

BUILD_RELEASE.ps1 performs:
  1. Build RR-V-Auth-Helper.exe as a separate process component
  2. Build RR-V as PyInstaller onedir
  3. Copy RR-V-Auth-Helper.exe beside RR-V.exe
  4. Verify yt-dlp / FFmpeg / FFprobe / Deno were not bundled accidentally

Expected output
  dist\RR-V\RR-V.exe
  dist\RR-V\RR-V-Auth-Helper.exe
  dist\RR-V\_internal\...
