Prepare YouTube support runtime
  powershell -ExecutionPolicy Bypass -File .\PREP_WPC_PROVIDER.ps1

The script rebuilds resources\wpc-provider\runtime from the exact regression-tested lock:
  yt-dlp-getpot-wpc 1.1.2 / nodriver 0.50.3 / mss 10.2.0 / websockets 16.1.1
  deprecated 1.3.1 / wrapt 2.3.0
It downloads each wheel with --no-deps, verifies the exact dist-info set, and removes
stale __pycache__ / .pyc files before packaging. The resulting Python source and
package metadata are bundled with RR-V.

Build
  powershell -ExecutionPolicy Bypass -File .\BUILD_RELEASE.ps1

BUILD_RELEASE.ps1 performs:
  1. Read APP_VERSION and verify RR-V.version_info.txt matches it
  2. Build RR-V-Auth-Helper.exe as a separate process component
  3. Build RR-V as PyInstaller onedir
  4. Copy RR-V-Auth-Helper.exe beside RR-V.exe
  5. Collect the RR-V core license and Korean convenience translation, third-party
     notices, source offer, Python/PySide/WPC license metadata, and RR-V Auth Helper
     source into the release
  6. Verify required release files and confirm yt-dlp / FFmpeg / FFprobe / Deno
     were not bundled accidentally

Build Installer
  powershell -ExecutionPolicy Bypass -File .\BUILD_INSTALLER.ps1

Expected output

BUILD_INSTALLER.ps1 verifies APP_VERSION and Inno Setup MyAppVersion match, creates
RRV_INSTALL_MANIFEST.txt from the exact dist\RR-V payload, checks required files and
forbidden bundled tools, compiles the Installer, then prints the final SHA-256.
